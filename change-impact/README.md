# Change Impact

**Status:** 🚧 In progress: method and worked example in first draft

**The question:** someone asks for one more change. Before you say yes, how far does it move the finish date, and what does it cost?

The usual answer is a guess. This folder replaces the guess with a method that uses the schedule's own dependencies, float and resources, and adds the part most programs leave out: **the fixed dates a slip can cross**, such as a contract that ends, a change freeze, or a commitment to a customer. Crossing one is not a cost per day. It is a step, and it is often the largest cost in the change.
